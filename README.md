# 🚀 RIDIVISE Frontend

RIDIVISE Frontend is a **responsive and interactive web interface** built using **HTML, CSS, and JavaScript**.  
It provides a clean UI for navigating different sections such as analytics, history, comparison, and contact pages.

🌐 **Live Demo:**  
👉 https://swati89923.github.io/RIDIVISE-FRONTEND/

---

## 📌 Features

- 🎨 Clean and modern UI design  
- 📊 Analytics page for data visualization layout  
- 📜 History section for past records  
- 🔍 Compare page for side-by-side insights  
- 📞 Contact page for user interaction  
- 📱 Fully responsive design  
- ⚡ Fast and lightweight (no frameworks)

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript**
- **Git & GitHub**
- **GitHub Pages** (Deployment)

---

## 🚀 Deployment

This project is deployed using **GitHub Pages**.

### Steps used for deployment:
1. Moved all frontend files to repository root
2. Enabled GitHub Pages from repository settings
3. Selected `main` branch and root folder
4. Accessed live site via GitHub Pages URL
